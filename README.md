# Konfekšu lietus

Spēles mērķis: savākt/noķert pēc iespējas vairāk konfektes grozā.

## Mapju struktūra un atvēršana
- `index.html` — galvenā spēles sākumlapa.
- `atteli/` — paša zīmēts PNG varonis (brūns groziņš).
- `skanas/` — spēles skaņas efekti (konfekšu krišanas skaņa, ķeršanas skaņa un uzvaras skaņa).

Atvēršana: atver `index.html` interneta pārlūkā no projekta mapes.

## Dizaina izvēles un pārbaude
- Gaiši roza fons ar tumšāki rozā tekstu rada jautru noskaņu un skaidru kontrastu. Veic domāt par bērnību un konfektēm.
- Spēles laukums ir centrēts un pielāgojas arī šauram pārlūka logam.
- Pārbaudīts: attēls, skaņa un punktu skaitītājs (3 klikšķi = 3 punkti) darbojas.
- Klasesbiedra atsauksme un uzlabojums: Ļoti labi izvēlētas krāsas ar pareizu noskaņu. Teksts un noteikumi saprotami. Varbūt nepieciešams mainīt ķeršanas skaņu.
